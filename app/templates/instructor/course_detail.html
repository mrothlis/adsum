Send attendance to D2L

📥 Export for D2L gradebook (recommended) Export grade column only, no per-date history Download spreadsheet for my own records

The recommended export carries two columns. Attendance is the numeric grade. Attendance Detail is a text column holding every class date and its status in one cell, so D2L keeps the whole record without one column per meeting. Text items are not counted in the final grade. Because that one cell holds the full history, a D2L grade export is a complete backup, and Restore from D2L below rebuilds this app from it. The grade-column-only file leaves out that history, so use it only if your D2L course already has an Attendance item you do not want changed. The spreadsheet is for you, not for D2L.

Putting the file into the D2L gradebook

  1. Click Export for D2L gradebook (recommended) above and save the file.
  2. In D2L go to Grades, then Import. Choose the file and tick Create new grade item when an unrecognized item is referenced. Tick that on your first import only.
  3. ⚠️ On New Grade Item Properties, set Maximum Points to 100 for Attendance. D2L defaults it to 10, which shows every student as 1000%. Attendance Detail is a Text item and needs no properties.
  4. Continue through the preview, then click Import.

Each import overwrites the Attendance column, it does not add to it. The export is always a running total for the semester, so a weekly import needs no tidying up. Scores are the percentage of sessions attended after the first {{ allowed_absences }} unexcused absences are forgiven. Excused absences are dropped from the count entirely. Anyone not on the D2L classlist is skipped as an unrecognized user, and that row is safe to ignore.

Roster and recovery

In D2L: Grades → Export, set Key Field to Username or Org Defined ID, tick Last Name and First Name under User Details, then Export to CSV. (Not the Classlist page; it has no export. The two name boxes are off by default, and without them the file has no names in it.) This is the only way Adsum learns about adds and drops; it cannot ask D2L itself. Existing students are matched on their D2L username and updated, not duplicated, and anyone missing from the file is marked as having dropped (their attendance is kept). You will get a list of exactly what changed.

D2L list says whether this student appeared in a classlist you imported. Not listed means Adsum created them from a D2L launch and has never seen them in an imported classlist. That is either a student who added the course since your last import (re-import the classlist and they will turn green), or somebody who should not be in this course at all. Either way their row will be rejected by D2L as an unrecognised user when you import grades, so it is worth resolving before the end of term.
