A course gets into Adsum one of two ways, and they lead to the same app — the same rotating QR code, the same roster import, the same attendance policy, the same exports. They differ only in how Adsum learns who scanned.

1. Launch it from D2L

Best if you have Brightspace. D2L tells Adsum the course name, the code and who you are, so nothing is typed twice — and because the LMS vouches for each student, nobody can check in as a classmate.

  1. In D2L, open the course.
  2. Go to Content.
  3. Choose Add Existing Activities, then External Learning Tool.
  4. Add the Adsum link.
  5. Click the link once. Come back here and the course will be listed.
{% if user.is_admin %}

The link needs an LTI key and secret before it will launch. You are an administrator, so you can set those now.

Set the LTI key and secret

{% else %}

If the link does not work, the LTI key and secret are not set yet. Ask whoever administers this server to set them.

{% endif %}

2. Create one here, for standalone use

Best if you have no LMS, or your institution's D2L is not an option. Nothing to configure: you import a roster, and the first time a student scans they pick their own name, which binds that phone to them for the term. Each name can only be claimed on one phone, and you are shown any clash.

Be aware of the trade: at that very first scan a student could pick a classmate's name. That is why one phone per name is enforced, why clashes are shown to you, and why you can release a binding. The D2L path is the stronger one.
